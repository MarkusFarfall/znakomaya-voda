# Поклёвка и вываживание: первый этап

Основа: `9558286`. Ветка: `feat/fishing-feedback`.

## Что изменилось

- До решительной поклёвки поплавок делает короткие касания. На экране —
  «Пробует — ждите», при потяжке — «Подсекайте!». У находок нейтральная подпись.
- Подход активной рыбы занимает 0,45–0,75 с, остальных — 0,9–1,45 с.
  Это короткая подготовка, а не новая полноценная система характеров.
- Ранний взмах отпугивает кандидата и запускает новое ожидание без потери наживки.
- Окно подсечки начинается **после** касаний. Базовые 1,3/1,15/1/0,9/0,8 с,
  бонус идеальной подсечки и множители снастей сохранены.
- Кольцо и расчёт идеальной подсечки используют один `inPerfectHookWindow`.
- Дополнительный случайный сильный рывок теперь предваряется сигналом за 0,55 с:
  звук, обводка рыбы, сообщение и полоска подготовки в HUD. Обычные чередования
  рывка/передышки сохранены. Прыжок или передышка отменяет подготовленный рывок.
- На HUD отдельно видны силы, накопленный перегруз и слабина. Риски нормированы
  фактическими игровыми пределами с учётом снастей и событий.
- Сход от слабины и уход слишком далеко объясняются разными сообщениями.
- Отмена касания, потеря захвата и фокуса сбрасывают подмотку/направление.
  Отмена зарядки не превращается в случайный заброс. Сенсорные стрелки захватывают
  указатель, чтобы отпускание снаружи кнопки не оставляло подмотку включённой.
- Окно настроек ставит механику на паузу и сбрасывает удержание.
- Колесо меняет только глубину. **Shift + колесо** меняет только зум.
  Ctrl + колесо оставлено браузеру. Инструкция в настройках обновлена.

## Границы изменения

Нет миграции сохранений: `nibbleTimer`, предупреждение рывка и ввод — временные
поля Engine/Hooked, не SaveData. Не изменены выбор видов, таблицы цен, награды,
снасти, авторизация, серверные API и производственная конфигурация безопасности.
Ручной фрикцион и отдельные профили борьбы видов — следующий этап, не эта ветка.

Предупреждение уменьшает частоту мгновенных дополнительных пиков: рывки больше
не могут накладываться на своё предупреждение и отменяются при передышке.
Это намеренная уступка читаемости; окончательную сложность стоит оценить в
продолжительном игровом тесте, особенно на эпических/легендарных видах.

## Файлы

- `src/game/fishing.ts`: общие константы и длительность подхода.
- `src/game/engine.ts`: жизненный цикл поклёвки, предупреждение, риски, исходы.
- `src/game/render/scene.ts`, `hud.ts`: поплавок, кольцо, визуальный сигнал, HUD.
- `src/game/audio.ts`: отдельные сигналы касания и подготовки рывка.
- `src/components/game/Game.tsx`, `SettingsModal.tsx`: ввод, пауза, инструкция.
- `tests/fishing.test.ts`, `tests/audio.test.ts`: регрессии механики и звука.

## Проверка

```sh
npm ci
npm run typecheck
npm run lint
npm test
npm run build
```

Для проверки базы нужен `TEST_DATABASE_URL` с отдельной тестовой PostgreSQL;
без него существующий DB-тест пропускается. Никакие боевые данные для проверки
рыбалки не нужны.

Браузерный чек-лист (desktop / телефон / горизонтальный телефон):

1. Забросить, дождаться касаний, не подсекать до уверенной потяжки.
2. Проверить ранний взмах, пропущенную, обычную и идеальную подсечку; повторить
   с улучшенным крючком — светлое кольцо должно совпадать с результатом.
3. Дождаться предупреждения сильного рывка, отпустить подмотку. В прыжке не мотать.
4. Накопить и сбросить перегруз/слабину; сравнить индикаторы и причины проигрыша.
5. Проверить колесо и Shift + колесо: глубина и зум не меняются одновременно.
6. Во время удержания уйти с кнопки и отпустить, отменить касание, переключить
   окно. Подмотка не должна залипать; отменённая зарядка не делает заброс.
7. Открыть настройки в борьбе: таймеры заморожены, после закрытия нет авто-подмотки.

Локально выполнены автоматические браузерные проверки независимости колеса,
отмены зарядки по blur, паузы настроек, pointercancel сенсорной стрелки и
отпускания за её пределами. Проверены кадры 1440×900, 390×844 и 844×390.
API в браузерной проверке изолированы: использовалось локальное тестовое сохранение,
запросы к аккаунтам/сохранениям перехватывались, реальная база не затрагивалась.
