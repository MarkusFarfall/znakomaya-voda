# Исходники судов

Здесь лежат исходные JPG с пурпурным фоном. Они **не отдаются браузеру** и не входят в
PWA-precache. В игру попадают уже обработанные WebP из `public/boats/`.

## Пересборка

```bash
npm run boats
npm run boats:check
```

Скрипт `scripts/prepare-boats.py` требует Pillow и выполняет:

1. тот же цветовой ключ, который раньше работал на устройстве игрока;
2. очистку краёв от примеси фона;
3. обрезку по фактическому силуэту;
4. уменьшение мастер-изображения до 1024 px с запасом для DPR=2;
5. сохранение в lossless WebP с альфа-каналом;
6. запись `public/boats/manifest.json` с размерами и SHA-256.

Повторная сборка детерминирована: манифест не содержит дату, а файлы перезаписываются
только при изменении содержимого. При обычной разработке запускать скрипт не нужно —
готовые WebP уже хранятся в репозитории. Запуск необходим только после замены исходника
или изменения алгоритма обработки.

Почему WebP, а не исходный JPG: браузер просто копирует bitmap и не выполняет
`getImageData` для удаления фона. Дальше работают прежние mip-уровни и подкраска.
